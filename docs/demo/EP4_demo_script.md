# EP4 데모 영상 스크립트

## 영상 정보

| 항목 | 내용 |
|------|------|
| 제목 | EP4 Gate 데모 — 제조사·R&D 연계: 산업 플랫폼 확장 |
| 예상 길이 | 5~7분 |
| 등장인물 | 나레이터(VO), 제조사 관리자(대동, 노트북), 의뢰자 김민준(앱), 마을 이장(앱) |
| 촬영 디바이스 | 아이폰(앱 화면) + 노트북(제조사 포털) |
| 배경 설정 | 전북 김제시 부량면, 대동 신형 트랙터 시험포 + 국가 R&D 실증 |

---

## 오프닝 (20초)

**[화면]** 단감 로고 애니메이션 → 타이틀 카드: "EP4 데모 — 제조사·R&D 연계"

**[나레이션]**
"EP4에서는 단감 플랫폼이 농기계 제조사와 국가 R&D 사업까지 연결되는 모습을 보여드립니다. 대동이 신형 트랙터 시험포를 모집하고, 농업인이 참여하여 데이터를 수집하는 과정, 그리고 농림부 실증사업에 마을 단위로 신청하는 과정입니다."

---

## Scene 1: 제조사 포털 로그인 (20초)

**[화면]** 노트북 — 제조사 포털 로그인 (대동)

**[나레이션]**
"대동의 담당자가 제조사 포털에 로그인합니다."

**[액션]** 로그인 → 제조사 대시보드 진입

**[화면]** "시험포 모집 등록" 메뉴

**[나레이션]**
"제조사 전용 대시보드에서 시험포 모집을 관리할 수 있습니다."

---

## Scene 2: 시험포 모집 등록 (40초)

**[화면]** "시험포 모집 등록" 클릭

**[액션]** 순서대로 입력:
1. 제품: 대동 RX8040 80마력 자동변속
2. 지역: 전북
3. 모집 인원: 10명
4. 조건: 2,000평 이상 보유
5. 혜택: 3개월 무상 대여
6. 카탈로그 + 사진 업로드

**[화면]** Toast "등록 완료"

**[나레이션]**
"대동 RX8040, 80마력 자동변속 트랙터를 전북 지역 10명에게 3개월간 무상으로 대여하는 시험포를 모집합니다. 2천 평 이상 농지를 보유한 농업인이 대상입니다."

> 촬영 포인트: 제품 사진, 무상 대여 조건을 클로즈업.

---

## Scene 3: 농업인 시험 참여 신청 (30초)

**[화면]** 전환 — 의뢰자 김민준 앱

**[화면]** 푸시 알림: "RX8040 시험포 모집"

**[액션]** 알림 탭 → "시험 참여 신청" 탭

**[화면]** 필지 정보 자동 연동 (부량면 3,000평)

**[화면]** Toast "신청 완료"

**[나레이션]**
"김민준에게 시험포 모집 알림이 왔습니다. 신청하면 이미 등록한 필지 정보가 자동으로 연동됩니다. 3천 평이면 조건을 충족하니 바로 신청 완료."

---

## Scene 4: 제조사 선정 (20초)

**[화면]** 전환 — 제조사 포털

**[화면]** "신청 23명" 표시

**[액션]** 김민준 클릭 → "선정" 클릭

**[화면]** 알림 자동 발송

**[나레이션]**
"23명이 신청했고, 제조사가 필지 조건과 위치를 검토한 후 김민준을 선정합니다."

---

## Scene 5: 시험 기간 — 주간 리포트 (40초)

**[화면]** 전환 — 김민준 앱 — 시험 진행 화면

**[나레이션]**
"시험 기간 중 매주 리포트를 제출합니다."

**[화면]** 주간 리포트 요청 알림

**[액션]** 순서대로 입력:
1. 작업일: 2027-01-15
2. 작업 면적: 1,500평
3. 연비: 시간당 8리터
4. 만족도: 4점
5. 특이사항: "경사지에서 변속이 부드러움"

**[액션]** 사진 3장 업로드 → "제출" 탭

**[나레이션]**
"작업일, 면적, 연비, 만족도를 입력하고 작업 사진을 첨부합니다. 이 데이터가 제조사의 제품 개선에 직접 활용됩니다."

> 촬영 포인트: 연비, 만족도 입력 필드를 클로즈업.

---

## Scene 6: 시험 종료 — 종합 리포트 (30초)

**[화면]** 전환 — 제조사 포털

**[나레이션]**
"시험이 종료되면 10곳의 데이터가 종합 리포트로 자동 생성됩니다."

**[화면]** 종합 리포트:
- 참여 농가: 10곳
- 평균 만족도: 4.6/5.0
- 평균 연비: 시간당 7.5리터
- 주요 피드백 요약
- 지역별 분석

**[액션]** "다운로드" 클릭

**[나레이션]**
"만족도 4.6점, 연비, 피드백까지 종합 리포트로 정리됩니다. 제조사는 이 데이터를 제품 개선과 마케팅에 활용할 수 있습니다."

---

## Scene 7: 국가 R&D 실증사업 신청 (40초)

**[화면]** 앱 — "국가 R&D 실증사업" 메뉴 탭

**[나레이션]**
"다음은 국가 R&D 실증사업 연계입니다."

**[액션]** "자율주행 농기계 실증" 선택 → "우리 마을 신청" 탭

**[화면]** 마을 선택: 부량면 신용리

**[화면]** 자동 집계:
- 참여 가구: 15가구
- 총 면적: 25ha

**[화면]** Toast "신청 접수"

**[나레이션]**
"자율주행 농기계 실증사업에 마을 단위로 신청합니다. 부량면 신용리, 15가구 25헥타르가 자동으로 집계되어 신청 접수됩니다. 개별 농가가 아니라 마을 단위로 신청하니 선정 가능성이 높아집니다."

> 촬영 포인트: 15가구, 25ha 자동 집계 화면을 클로즈업.

---

## Scene 8: R&D 선정 + 첨단 농가 DB (30초)

**[화면]** 선정 알림 수신

**[나레이션]**
"실증사업에 선정되었습니다."

**[화면]** 첨단 농가 DB 자동 등록 확인

**[화면]** 제조사 매칭 완료 화면

**[나레이션]**
"선정된 농가는 첨단 농가 데이터베이스에 자동으로 등록됩니다. 향후 자율주행 트랙터, 스마트팜 장비 제조사와의 매칭에 우선적으로 참여할 수 있습니다. 단감 플랫폼이 농업인과 제조사, 그리고 국가 R&D를 하나로 연결합니다."
