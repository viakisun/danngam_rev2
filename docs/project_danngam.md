### 마일스톤 1: EP1 Gate — 시스템 초기 데이터 구축 + 작업자 온보딩

| 항목 | 값 |
|------|-----|
| 이름 | EP1 Gate — 시스템 초기 데이터 구축 + 작업자 온보딩 |
| 목표일 | 2026-05-30 |
| 상태 | `pending` |
| 데모 주차 | W13 |

**산출물:**
- 농기계-농작업 매칭 기초 데이터베이스 (시기별 농작업 × 필요 농기계 × 스펙 범위)
- 농기계 등록 시스템 (카테고리 검색 + 직접 입력 + 사진 업로드)
- 농기계 조회 화면 (위치 기반 반경 검색, 시기별 추천 작업 연동)
- 작업자 프로필 + 장비 카드 (사진, 스펙, 가격, 평판)
- 다중 인증 시스템 (소셜로그인 우선 + SMS + 이메일) + 위치 권한 + 홈 화면
- 백오피스 초기 데이터 입력 도구 (엑셀 업로드 + 수동 입력 폼)

**통과 게이트 조건:**
> 소셜로그인(카카오/네이버) 또는 SMS/이메일 인증 → 위치 확인 → 주변 장비 조회 → 장비 상세 → 시기별 추천 작업 확인까지 전 과정 오류 없이 완료. 초기 데이터 50건 이상 등록 확인.

**데모 시나리오:**

요약:
> 백오피스에서 농기계-농작업 기초 데이터를 구축하고, 작업자(장비 보유자)가 앱에 가입하여 장비를 등록하고, 일반 사용자가 주변 장비를 조회하는 전 과정 시연.

Micro Steps:
1. [Click] 백오피스 로그인 → [State] 관리자 대시보드 진입 → [Auto] "초기 데이터 구축" 배너 표시
2. [Click] "농작업-농기계 매칭 DB 관리" → [Panel] 시기별 농작업 테이블 → [Input] 3월/벼/로터리작업/트랙터(30마력 이상)+로터리/평당 3,000~5,000원 → [Click] 저장 → [Toast] 등록 완료
3. [Click] "농기계 카테고리 관리" → [Input] 트랙터 > 대동 RX7630 > 76마력/4WD/로터리 호환 → [Upload] 제품 이미지 2장 → [Click] 저장 → [Toast] 카테고리 추가
4. [Click] "데이터 일괄 업로드" → [Upload] 초기데이터_농기계_v1.xlsx (50건) → [Auto] 유효성 검사 → [Toast] "48건 성공, 2건 오류" → [Modal] 오류 상세 (중복 모델명, 누락 필드)
5. [Click] 앱 실행 → [State] 로그인 화면 — "카카오로 시작하기" / "네이버로 시작하기" / "휴대폰 번호로 시작" / "이메일로 시작" → [Click] "카카오로 시작하기" → [Auto] 카카오 인증 완료 → [Modal] 위치 권한 요청 → [Click] 허용 → [State] 홈 화면 진입 (현재 위치: 김제시 부량면)
6. [Auto] 홈 화면 — "주변 5km 장비 3건" 배너 + "3월 추천 작업: 로터리 작업" 카드 표시

8. [Click] 첫 번째 장비 카드 → [Panel] 장비 상세 — 대동 RX7630 76마력, 부착 장비 (로터리/쟁기/배토기), 보유자: 이철수, 경력 15년, 평점 4.8
9. [Click] "내 장비 등록" (작업자 모드) → [Select] 카테고리: 트랙터 → [Select] 모델: 대동 RX7630 → [Auto] 스펙 자동 입력(76마력/4WD) → [Upload] 장비 사진 3장 → [Input] 부착 장비: 로터리, 쟁기 (체크박스) → [Input] 작업 가능 지역: 김제시 전체 (반경 20km) → [Input] 희망 가격: 평당 4,000원 → [Click] 등록 완료 → [Toast] "장비가 등록되었습니다!"
10. [Click] 홈 → [Auto] "이번 달 추천 작업" 섹션 — "3월: 로터리 의뢰 12건 / 4월: 모내기 8건 / 9월: 벼베기 예정 23건" → [Click] "9월 벼베기" → [Click] 알림 설정 → [Toast] "9월 벼베기 의뢰 알림이 설정되었습니다."

### 마일스톤 2: EP2 Gate — 의뢰자 온보딩 + 매칭/거래 + 건조위탁 + 결제

| 항목 | 값 |
|------|-----|
| 이름 | EP2 Gate — 의뢰자 온보딩 + 매칭/거래 + 건조위탁 + 결제 |
| 목표일 | 2026-09-12 |
| 상태 | `pending` |
| 데모 주차 | W28 |

> ※ 건조위탁 + 결제 모듈 추가로 EP2 Gate를 2주 연장 (08-29 → 09-12)

**산출물:**
- 의뢰자 필지 등록 시스템 (주소 검색 + 면적 입력 + 지도 마킹)
- 연간 농작업 캘린더 등록 (필지별 작기 스케줄)
- 의뢰 등록 + 자동 추천 매칭 (필지/시기/작업 기반)
- 1:1 채팅 협의 + 계약/거래 체결
- 작업 수행 → 피드백/평가 → 정산
- **건조시설 검색 + 건조 위탁 시스템 (시설 조회/예약/입고/수율·품질 기록/출고)**
- **에스크로 결제 시스템 (PG 연동 + 의뢰자 결제 → 작업 확인 → 작업자 정산)**
- 수익 대시보드 (작업자용) + "이번주 우리동네 수입왕" 리더보드
- 평판 시스템 (거래 건수 + 평점 + 응답률 + 완료율)
- 가격 통계 (최근 평균 거래 가격 안내)

**통과 게이트 조건:**
> 의뢰자 필지 등록 → 작업 등록 → 자동 추천 → 채팅 → 계약 → **에스크로 결제** → 작업 완료 → **건조 위탁(입고→건조→수율/품질 기록→출고)** → 평가 → **자동 정산** 전 사이클 오류 없이 완료.

**데모 시나리오:**

요약:
> 의뢰자(김민준)가 필지를 등록하고 벼베기를 의뢰하면, 시스템이 작업자(이철수)를 자동 추천. 채팅 → 계약 → 에스크로 결제 → 작업 수행 → 건조시설 위탁(부량 건조장) → 수율/품질 기록 → 평가 → 자동 정산까지 전 과정.
