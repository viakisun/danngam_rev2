EP1 데모 — 초기 데이터 구축부터 장비 등록까지

3월의 김제시. 봄 농사 준비가 한창입니다.

먼저 관리자 박소연이 백오피스에 로그인합니다. "농작업-농기계 매칭 DB 관리" 메뉴에서 시기별 농작업 데이터를 입력합니다 — "3월 / 벼 / 로터리 작업 / 트랙터(30마력 이상) + 로터리 / 평당 3,000~5,000원". 이어서 농기계 카테고리에 "트랙터 > 대동 RX7630 > 76마력/4WD"를 등록하고 제품 이미지를 올립니다. 마지막으로 엑셀 파일 하나로 50건의 초기 데이터를 일괄 업로드합니다. 48건 성공, 2건은 중복 모델명과 누락 필드로 오류 — 바로 수정합니다.

한편, 부량면에서 트랙터를 보유한 작업자 이철수씨가 앱을 켭니다. "카카오로 시작하기"를 누르고, 위치 권한을 허용합니다. 홈 화면에 "주변 5km 장비 3건" 배너와 "3월 추천 작업: 로터리 작업" 카드가 보입니다.

이철수씨는 "주변 장비 보기"를 눌러 근처 장비 3건을 확인하고, 첫 번째 장비 카드를 탭해 상세 정보 — 대동 RX7630 76마력, 부착 장비(로터리/쟁기/배토기), 보유자 정보, 시간당 가격 — 를 살펴봅니다.

그리고 직접 "내 장비 등록"을 시작합니다. 카테고리에서 트랙터를 선택하면 스펙이 자동 입력됩니다. 장비 사진 3장을 올리고, 부착 장비(로터리, 쟁기)를 체크하고, 작업 가능 지역을 "김제시 전체(반경 20km)", 희망 가격을 "평당 4,000원"으로 설정합니다. 등록 완료!

홈으로 돌아오면 "이번 달 추천 작업" 섹션이 보입니다 — 3월 로터리 의뢰 12건, 4월 모내기 8건, 9월 벼베기 예정 23건. 이철수씨는 "9월 벼베기"를 눌러 알림을 설정합니다. "9월 벼베기 의뢰 알림이 설정되었습니다."

EP2 DEMO NARRATIVE — 이야기로 보는 매칭/거래 전 과정

EP2 데모 — 필지 등록에서 정산까지, 매칭의 완성

9월, 부량면에 가을바람이 불기 시작합니다. 벼베기 시즌입니다.

의뢰자 김민준씨는 먼저 자신의 농지를 앱에 등록합니다. "전북 김제시 부량면 신용리 산 12번지, 3,000평, 벼" — 카카오맵에 핀이 찍히고 농지가 저장됩니다. 이어서 "연간 작업 캘린더"를 열면 AI가 추천합니다: "3월 로터리, 5월 모내기, 6~8월 방제 3회, 9월 벼베기". 전체 수락!

9월 1일, 김민준씨의 폰에 푸시 알림이 뜹니다. "벼베기 시즌입니다! 주변 콤바인 보유 작업자 5명을 찾았습니다." 의뢰를 등록합니다 — 필지 정보가 자동 입력되고, 시스템이 "최근 평균 거래 가격: 평당 4,500원"을 안내합니다. 희망일 9/15~20, 예산 평당 5,000원(총 1,500만원)으로 등록하면, 적합한 작업자들에게 즉시 알림이 갑니다.

작업자 이철수씨(★4.8, 2km)가 알림을 확인하고 지원합니다. "R532 콤바인 보유, 9/15 오전 6시 작업 가능합니다." 다른 2명도 지원합니다. 김민준씨는 가장 가깝고 평점 높은 이철수씨를 선택합니다.

채팅방이 열립니다. 진입로 확인, 일정 조율, 금액 합의 — 평당 5,000원, 총 1,500만원. 계약 체결 버튼으로 인앱 계약서에 양측이 서명합니다.
