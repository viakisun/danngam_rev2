# EP1 데모 영상 스크립트

## 영상 정보

| 항목 | 내용 |
|------|------|
| 제목 | EP1 Gate 데모 — 시스템 초기 데이터 구축 + 작업자 온보딩 |
| 예상 길이 | 5~7분 |
| 등장인물 | 나레이터(VO), 관리자(백오피스), 작업자 이철수(앱), 일반 사용자(앱) |
| 촬영 디바이스 | 아이폰(앱 화면 녹화) + 노트북(백오피스 화면 녹화) |
| 배경 설정 | 전북 김제시 부량면, 3월 로터리 시즌 |

---

## 오프닝 (20초)

**[화면]** 단감 로고 애니메이션 → 타이틀 카드: "EP1 데모 — 초기 데이터 구축 + 작업자 온보딩"

**[나레이션]**
"단감은 농기계를 보유한 작업자와 농작업이 필요한 의뢰자를 연결하는 O2O 플랫폼입니다. 오늘은 시스템의 첫 번째 단계, 초기 데이터 구축부터 작업자가 장비를 등록하고 주변 장비를 조회하는 과정까지 보여드리겠습니다."

---

## Scene 1: 백오피스 로그인 (20초)

**[화면]** 노트북 — 백오피스 로그인 화면

**[나레이션]**
"먼저 관리자가 백오피스에 로그인합니다."

**[액션]** 관리자 계정으로 로그인

**[화면]** 대시보드 진입 → "초기 데이터 구축" 배너 표시

**[나레이션]**
"대시보드에 초기 데이터 구축 안내가 표시됩니다. 단감의 핵심은 시기별로 어떤 농작업에 어떤 농기계가 필요한지를 체계적으로 관리하는 것입니다."

---

## Scene 2: 농작업-농기계 매칭 DB 입력 (40초)

**[화면]** "농작업-농기계 매칭 DB 관리" 메뉴 클릭

**[나레이션]**
"농작업-농기계 매칭 데이터베이스를 구축합니다. 시기별 농작업과 필요한 농기계, 스펙 범위, 가격대를 입력합니다."

**[액션]** 시기별 농작업 테이블에 데이터 입력
- 시기: 3월
- 작물: 벼
- 작업: 로터리 작업
- 필요 장비: 트랙터 30마력 이상 + 로터리
- 가격 범위: 평당 3,000~5,000원

**[화면]** 저장 → Toast "등록 완료"

**[나레이션]**
"3월 벼 로터리 작업에는 30마력 이상 트랙터와 로터리가 필요하고, 현장 시세는 평당 3천 원에서 5천 원 사이입니다."

> 촬영 포인트: 입력 필드를 하나씩 채우는 과정을 클로즈업. 특히 "평당" 단위가 보이도록.

---

## Scene 3: 농기계 카테고리 관리 (30초)

**[화면]** "농기계 카테고리 관리" 클릭

**[나레이션]**
"다음으로 농기계 카테고리를 등록합니다. 제조사, 모델명, 마력, 구동 방식 같은 상세 스펙과 함께 제품 이미지도 등록합니다."

**[액션]**
- 카테고리: 트랙터
- 모델: 대동 RX7630
- 스펙: 76마력, 4WD, 로터리 호환
- 이미지 2장 업로드

**[화면]** 저장 → Toast "카테고리 추가 완료"

**[나레이션]**
"대동 RX7630, 76마력 4륜 구동 트랙터가 등록되었습니다."

---

## Scene 4: 엑셀 일괄 업로드 (30초)

**[화면]** "데이터 일괄 업로드" 클릭

**[나레이션]**
"대량의 데이터는 엑셀 파일로 한꺼번에 업로드할 수 있습니다."

**[액션]** 초기데이터_농기계_v1.xlsx (50건) 업로드

**[화면]** 유효성 검사 진행 → "48건 성공, 2건 오류" → 오류 상세 모달 (중복 모델명, 누락 필드)

**[나레이션]**
"50건을 업로드하면 시스템이 자동으로 유효성을 검사합니다. 48건이 성공하고, 중복 모델명과 필수 필드 누락으로 2건이 오류로 표시되었습니다. 이렇게 초기 데이터 50건 이상을 빠르게 구축할 수 있습니다."

> 촬영 포인트: 오류 상세 모달을 잠시 보여준 후 닫기.

---

## Scene 5: 앱 로그인 + 홈 화면 (40초)

**[화면]** 전환 — 아이폰 앱 실행

**[나레이션]**
"이제 작업자 입장에서 앱을 사용해 보겠습니다."

**[화면]** 로그인 화면 — "카카오로 시작하기" / "네이버로 시작하기" / "휴대폰 번호로 시작" / "이메일로 시작"

**[나레이션]**
"단감은 카카오, 네이버 소셜 로그인을 지원합니다. 카카오로 시작하기를 눌러보겠습니다."

**[액션]** "카카오로 시작하기" 탭 → 카카오 인증 완료

**[화면]** 위치 권한 요청 모달

**[나레이션]**
"인증이 완료되면 위치 권한을 요청합니다. 주변 장비를 찾으려면 현재 위치가 필요합니다."

**[액션]** "허용" 탭

**[화면]** 홈 화면 진입 — 현재 위치: 김제시 부량면

**[나레이션]**
"홈 화면에 진입했습니다. 현재 위치는 전북 김제시 부량면입니다."

---

## Scene 6: 홈 화면 — 주변 장비 + 추천 (20초)

**[화면]** 홈 화면 상단 — "주변 5km 장비 3건" 배너 + "3월 추천 작업: 로터리 작업" 카드

**[나레이션]**
"홈 화면에서 주변 5킬로미터 이내 등록된 장비 3건이 바로 보이고, 3월에 맞는 추천 작업으로 로터리 작업이 표시됩니다. 아까 관리자가 입력한 시기별 데이터가 여기에 반영되는 겁니다."

> 촬영 포인트: "주변 5km 장비 3건" 배너와 "3월 추천" 카드를 함께 보여줄 것.

---

## Scene 7: 장비 리스트 (20초)

**[화면]** "주변 장비 보기" 탭

**[나레이션]**
"주변 장비를 눌러보면 반경 5킬로미터 내 장비 리스트가 나옵니다."

**[화면]** 장비 카드 3건 — 사진 + 모델명 + 보유자 + 거리 + 평점

**[나레이션]**
"각 장비 카드에 사진, 모델명, 보유자 이름, 거리, 평점이 한눈에 보입니다."

---

## Scene 8: 장비 상세 (20초)

**[화면]** 첫 번째 장비 카드 탭

**[나레이션]**
"장비를 탭하면 상세 정보를 확인할 수 있습니다."

**[화면]** 장비 상세 — 대동 RX7630 76마력, 부착 장비(로터리/쟁기/배토기), 보유자: 이철수, 경력 15년, 평점 4.8

**[나레이션]**
"대동 RX7630 76마력 트랙터, 로터리와 쟁기, 배토기를 보유하고 있고, 경력 15년에 평점 4.8점인 이철수 작업자의 장비입니다."

---

## Scene 9: 내 장비 등록 (50초)

**[화면]** "내 장비 등록" 버튼 탭 (작업자 모드)

**[나레이션]**
"이번에는 직접 장비를 등록해 보겠습니다."

**[액션]** 순서대로 입력:
1. 카테고리: 트랙터
2. 모델: 대동 RX7630
3. (자동 입력) 스펙: 76마력, 4WD

**[나레이션]**
"카테고리에서 트랙터를 선택하고 모델을 고르면, 아까 관리자가 등록한 스펙이 자동으로 입력됩니다."

**[액션]** 계속 입력:
4. 장비 사진 3장 업로드
5. 부착 장비: 로터리, 쟁기 (체크박스)
6. 작업 가능 지역: 김제시 전체 (반경 20km)
7. 희망 가격: 평당 4,000원

**[화면]** "등록 완료" 탭 → Toast "장비가 등록되었습니다!"

**[나레이션]**
"사진 3장과 부착 장비를 체크하고, 작업 가능 지역을 김제시 전체 반경 20킬로미터로 설정합니다. 희망 가격은 평당 4천 원. 등록 완료!"

> 촬영 포인트: 체크박스 선택, 지역 슬라이더, 가격 입력을 순서대로 보여줄 것.

---

## Scene 10: 시기별 추천 + 알림 설정 (30초)

**[화면]** 홈 화면으로 돌아가기

**[나레이션]**
"홈 화면의 '이번 달 추천 작업' 섹션을 보겠습니다."

**[화면]** "3월: 로터리 의뢰 12건 / 4월: 모내기 8건 / 9월: 벼베기 예정 23건"

**[나레이션]**
"시기별 추천 작업이 표시됩니다. 3월에는 로터리 의뢰 12건, 9월에는 벼베기 23건이 예정되어 있습니다."

**[액션]** "9월 벼베기" 탭 → "알림 설정" 탭

**[화면]** Toast "9월 벼베기 의뢰 알림이 설정되었습니다."

**[나레이션]**
"9월 벼베기 시즌이 오면 자동으로 알림을 받을 수 있도록 설정했습니다."

---
