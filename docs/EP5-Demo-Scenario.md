# EP5 데모 시나리오 — 데이터/AI + 스케줄링

## 시나리오 A — 데이터/AI

### Step 1: 대시보드
- "데이터 분석" → 전국 히트맵 + 추이 + "9월 벼베기 D-30"

### Step 2: 수요 예측
- "AI 수요 예측" → 전국 12,400건(+8%) / 김제 420건 vs 작업자 85명 → 부족률 15%

### Step 3: AI Agent
- 익산 12명, 정읍 8명에게 자동 알림

### Step 4: 가격 예측
- 김제 벼베기 평당 4,800원(+6.7%) / 건조위탁비 가마당 3,200원(+7%)

### Step 5: 정책 리포트
- "정책 리포트 생성" → 전북도청 → AI 리포트 → "발송"

### Step 6: 데이터 API
- API 키 발급 → 접근 범위 설정

### Step 7: 수출 이력
- 로터리 → 모내기 → 방제 → 벼베기 → 건조(부량, 수율 86%, 1등급) → 도정 → QR 증명서

### Step 8: 종합 통계
- 사용자 45,000명 / 장비 8,500대 / 거래 102,000건 / 거래액 2,340억
- 건조 위탁 12,000건 / 대행단 120개 / 보조금 185억 / AI 정확도 92%

## 시나리오 B — 전국 대형장비 스케줄링

> 해남 대형장비팀 콤바인 전국 이동 + AI 경로 최적화

### Step 1: 스케줄 보드
- 전국 지도 + 대형 장비 마커 — 6조식 콤바인 42대, 드론 편대 28팀, 자율주행 15대

### Step 2: 대행단 상세
- "해남 대형장비팀" → DC130, ER6120, 운반 트럭 1대, 멤버 4명
- 9월: 해남(9/5~10) → 영광(9/12~14) → 김제(9/16~20 비어있음) → 당진(9/22~26)

### Step 3: 대형 장비 검색
- 6조식 콤바인 / 9/15~20 / 김제 부량면
- "해남 대형장비팀 DC130 (9/16~20 가용, 180km)" / "익산 콤바인팀 (9/18~20만)"

### Step 4: 의뢰 상세
- 9/16 도착 / 1일 5,000평 / 4일 20,000평 / 평당 3,500원(대형 할인) → "의뢰 신청"

### Step 5: AI 경로 최적화
- 해남→영광→김제 부량(신규)→김제 백산(기존)→당진 / 공차 2일→1일 단축

### Step 6: 스케줄 확정
- 대행단 대표 "김제 부량 20,000평" 수락 → 스케줄 확정 → 의뢰자 알림
