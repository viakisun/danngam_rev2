# EP3 데모 시나리오 — 보조금 + 대행단

## 시나리오 A — 지자체 보조금

> 김제시청 항공방제 보조금 등록 → 농업인 신청 → 작업 → 리포트 → 정산

### Step 1: 지자체 로그인
- 백오피스 (김제시청) → 지자체 대시보드 → "보조금 사업 등록"

### Step 2: 사업 등록
- 항공방제 보조금 / 예산 5억 / 드론 방제 / 70% 지원 / 한도 500만 / 06-01~08-31

### Step 3: 농업인 알림
- 김민준 푸시: "항공방제 보조금 (70%)" → 보조금 신청 화면

### Step 4: 보조금 신청
- 필지: 부량면 3,000평(벼) → 예상 300만/보조금 210만/자부담 90만 → 신청

### Step 5: 승인
- 지자체 "신청 42건 대기" → 김민준 건 승인 → 농업인 알림

### Step 6: 보조금 연계 매칭
- 이철수 드론팀(대행단) 우선 추천 → 채팅 → 보조금 연계 계약

### Step 7: 작업 + 리포트
- 완료 → 드론 비행 로그 + GPS + 방제 사진 → PDF 자동 생성

### Step 8: 지자체 발송
- "리포트 확인" → "지자체 발송" → API 전송

### Step 9: 정산
- 지자체 "정산 대기 15건" → 승인 → 대행단 계좌 210만 + 자부담 90만

### Step 10: 집행 현황
- 총 5억 / 집행 2.1억(42%) / 잔여 2.9억 / 수혜 98명 / 완료 84건

## 시나리오 B — 농작업 대행단

> 부량 콤바인팀 생성 → 벼베기 12건 그룹 수주 → 자동 할당 → 정산

### Step 1: 대행단 생성
- "대행단 만들기" → 부량 콤바인팀 / 대표 이철수 / 벼베기+로터리 / 김제시 30km
- 팀 로고 + 작업 사진 5장

### Step 2: 멤버 초대
- 박영호(R432), 김수현(DC70), 최동훈(RX7630+로터리), 한서준(MT545+배토기)
- 4명 수락 → 멤버 5명, 장비 8대

### Step 3: 프로필
- "부량 콤바인팀 | 5명 | 콤바인 3+트랙터 2 | 4.9점 | 47건 완료"

### Step 4: 그룹 수주
- 9월 의뢰 12건 (36,000평) → 대표 "수주 확인"

### Step 5: 자동 할당
- 이철수(4건/12,000평/부량), 박영호(3건/9,000평/죽산), 김수현(3건/8,000평/백산)
- 최동훈(1건/4,000평 로터리), 한서준(1건/3,000평 로터리)
- 기준: 장비적합도 40% + 위치근접도 30% + 가용일정 30%

### Step 6: 할당 수정
- 대표 이철수 → 박영호 1건을 김수현으로 변경 (2km 더 가까움) → "할당 확정"

### Step 7: 작업 진행
- 각 멤버 "할당된 작업 4건" → 일정별 작업 목록

### Step 8: 그룹 정산
- 12건 완료 / 총 1.8억 / 이철수 6천만, 박영호 3천만, 김수현 4,500만...
- 수수료 3% 차감 → 각 멤버 계좌 입금
