# EP2 데모 시나리오 — 매칭/거래 + 건조위탁 + 결제

> 필지 등록 → 의뢰 → 매칭 → 채팅 → 계약 → 에스크로 → 작업 → 건조위탁 → 평가 → 정산

## Micro Steps

### Step 1: 필지 등록
- [Click] "내 농지 등록" → 전북 김제시 부량면 신용리 산 12번지 → 카카오맵 핀 → 3,000평/벼

### Step 2: 연간 캘린더
- [Click] "연간 작업 캘린더" → AI 추천: "3월 로터리, 5월 모내기, 6~8월 방제, 9월 벼베기, 10월 건조위탁"
- [Click] "전체 수락"

### Step 3: 시즌 알림
- [Auto] 9/1 푸시: "벼베기 시즌! 콤바인 작업자 5명" → 추천 리스트 (이철수 4.8점/2km)

### Step 4: 의뢰 등록
- [Auto] 필지 자동입력 → 벼베기 → 9/15~20 → "최근 평균: 평당 4,500원" → 예산 5,000원 (총 1,500만원)

### Step 5: 작업자 지원
- [Auto] 이철수 앱 → 푸시 "부량면 벼베기 3,000평" → "지원하기" → "R532 콤바인, 9/15 오전 6시"

### Step 6: 선택 + 매칭
- 의뢰자 "지원자 3명" → 이철수 선택 → "매칭 완료, 채팅방 생성"

### Step 7-8: 채팅 + 계약
- 채팅: 일정/진입로/금액 확인 → "계약 체결" → 계약서(작업/면적/금액/일시) → 양측 동의

### Step 9: 에스크로 결제
- 결제 화면 → 토스페이먼츠/카드/계좌이체 → 1,500만원 결제 → "에스크로 보관 중"

### Step 10: 작업 완료
- 9/15 완료 → 사진 3장 → 면적 3,000평/시간 8시간 → 의뢰자 알림

### Step 11: 건조시설 검색
- "건조시설 찾기" → 부량 건조장(2km, 가마당 3,000원), 죽산 건조장(5km, 2,800원)
- 부량 건조장 상세 (순환식, 예상 3일)

### Step 12: 건조 위탁 신청
- 입고: 2026-09-16 / 50가마(벼) / 목표 수분율 14%

### Step 13: 건조 진행
- 입고 확인 → 현재 수분율 22% → 목표 14% → 예상 완료 09-19

### Step 14: 수율/품질
- 투입 50가마 → 산출 43가마(현미) / 수율 86% → 등급 1등급, 수분 13.8%, 동할미율 2.1% → 출고

### Step 15: 평가
- 의뢰자 "작업 확인 완료" → ★5점 + "깔끔하게 작업" → 평가 완료

### Step 16: 자동 정산
- 에스크로 정산: 1,500만원 → 수수료 3%(45만원) → 1,455만원 입금
- 건조비: 50가마 × 3,000원 = 15만원 별도

### Step 17: 수익 대시보드
- 이번 주: 1,455만원 / 이번 달: 2,850만원 / 평점 4.9 / 리더보드 1위
