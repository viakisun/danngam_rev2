### 마일스톤 1: EP1 Gate — 시스템 초기 데이터 구축 + 작업자 온보딩

| 항목 | 값 |
|------|-----|
| 이름 | EP1 Gate — 시스템 초기 데이터 구축 + 작업자 온보딩 |
| 목표일 | 2026-05-30 |
| 상태 | `pending` |
| 데모 주차 | W13 |

**산출물:**
- 농기계-농작업 매칭 기초 데이터베이스 (시기별 농작업 × 필요 농기계 × 스펙 범위)
- 농기계 등록 시스템 (카테고리 검색 + 직접 입력 + 사진 업로드)
- 농기계 조회 화면 (위치 기반 반경 검색, 시기별 추천 작업 연동)
- 작업자 프로필 + 장비 카드 (사진, 스펙, 가격, 평판)
- 소셜로그인 + 위치 권한 + 홈 화면
- 백오피스 초기 데이터 입력 도구 (엑셀 업로드 + 수동 입력 폼)

**통과 게이트 조건:**
> E1-A01~E01 전 화면 조건부 승인: 소셜로그인 → 위치 확인 → 주변 장비 조회 → 장비 상세 → 시기별 추천 작업 확인까지 전 과정 오류 없이 완료. 초기 데이터 50건 이상 등록 확인.

**데모 시나리오:**

요약:
> 백오피스에서 농기계-농작업 기초 데이터를 구축하고, 작업자(장비 보유자)가 앱에 가입하여 장비를 등록하고, 일반 사용자가 주변 장비를 조회하는 전 과정 시연. "김제 인근 주요 농기계 보유자 5명의 장비 데이터가 사전 등록된 상태"를 전제로 시작.

|------|-----|
| 이름 | EP2 Gate — 의뢰자 온보딩부터 거래 성사까지: 매칭의 완성 |
| 목표일 | 2026-08-29 |
| 상태 | `pending` |
| 데모 주차 | W26 |

**산출물:**
- 의뢰자 필지 등록 시스템 (주소 검색 + 면적 입력 + 지도 마킹)
- 연간 농작업 캘린더 등록 (필지별 작기 스케줄)
- 의뢰 등록 + 자동 추천 매칭 (필지/시기/작업 기반)
- 1:1 채팅 협의 + 계약/거래 체결
- 작업 수행 → 피드백/평가 → 정산
- 수익 대시보드 (작업자용) + "이번주 우리동네 수입왕" 리더보드

- 가격 통계 (최근 평균 거래 가격 안내, 장비/지역/작업별)

**통과 게이트 조건:**
