# EP2 데모 영상 스크립트

## 영상 정보

| 항목 | 내용 |
|------|------|
| 제목 | EP2 Gate 데모 — 매칭·거래·건조·정산 전 사이클 |
| 예상 길이 | 8~10분 |
| 등장인물 | 나레이터(VO), 의뢰자 김민준(앱), 작업자 이철수(앱), 건조장 운영자(앱) |
| 촬영 디바이스 | 아이폰 2대(의뢰자/작업자 동시) + 노트북(건조장 화면) |
| 배경 설정 | 전북 김제시 부량면, 9월 벼베기 시즌 |

## 오프닝 (20초)

**[화면]** 단감 로고 애니메이션 → 타이틀 카드: "EP2 데모 — 매칭·거래·건조·정산 전 사이클"

**[나레이션]**
"EP1에서 초기 데이터 구축과 작업자 온보딩을 마쳤습니다. 오늘은 의뢰자가 필지를 등록하고, 작업을 의뢰하고, 에스크로 결제부터 건조 위탁, 평가, 정산까지 전체 사이클을 보여드리겠습니다."

## Scene 1: 필지 등록 (40초)

**[화면]** 의뢰자 김민준 앱 — 홈 화면

**[나레이션]**
"의뢰자 김민준이 자신의 농지를 등록합니다."

**[액션]** "내 농지 등록" 탭

**[화면]** 농지 등록 화면

**[액션]** 순서대로 입력:
1. 주소: 전북 김제시 부량면 신용리 산 12번지
2. 카카오맵 핀 자동 표시
3. 면적: 3,000평
4. 작물: 벼

**[화면]** 저장 → Toast "농지가 등록되었습니다."

**[나레이션]**
"주소를 입력하면 지도에 핀이 자동으로 찍히고, 면적 3천 평, 작물 벼를 등록합니다."

> 촬영 포인트: 카카오맵에 핀이 찍히는 순간과 면적 입력을 클로즈업.
