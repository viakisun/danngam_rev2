# EP4 데모 시나리오 — 제조사/R&D 연계

> 대동 시험포 모집 → 농업인 참여 → 데이터 수집 → R&D 실증사업

## Micro Steps

### Step 1: 제조사 포털
- [Click] 제조사 포털 로그인 (대동) → "시험포 모집 등록"

### Step 2: 시험포 등록
- 대동 RX8040 80마력 자동변속 / 전북 / 10명 / 3개월 무상 대여 / 2,000평+
- 카탈로그+사진 업로드

### Step 3: 농업인 신청
- 김민준 푸시: "RX8040 시험포 모집" → "시험 참여 신청" → 필지 연동

### Step 4: 선정
- 제조사 "신청 23명" → 김민준 → "선정" → 알림

### Step 5: 데이터 수집
- 주간 리포트: 작업일/면적/연비/만족도/특이사항 → 사진 → 제출

### Step 6: 종합 리포트
- 10곳 종합: 만족도 4.6, 연비, 피드백 → 다운로드

### Step 7: R&D 실증
- "국가 R&D 실증사업" → "자율주행 농기계 실증" → "우리 마을 신청"
- 부량면 신용리 → 15가구, 25ha

### Step 8: 선정 + 매칭
- 선정 알림 → 첨단 농가 DB 자동 등록 → 제조사 매칭
