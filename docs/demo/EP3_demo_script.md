# Part A: 지자체 보조금 연계

---

## Scene 1: 지자체 로그인 + 보조금 사업 등록 (40초)

**[화면]** 노트북 — 백오피스 로그인 (김제시청)

**[나레이션]**
"먼저 지자체 보조금 연계입니다. 김제시청 관리자가 백오피스에 로그인합니다."

**[화면]** 지자체 대시보드 진입

**[액션]** "보조금 사업 등록" 클릭

**[화면]** 보조금 사업 등록 화면

**[액션]** 순서대로 입력:
1. 사업명: 항공방제 보조금
2. 총 예산: 5억원
3. 대상 작업: 드론 방제
4. 지원 비율: 70%
5. 건당 한도: 500만원
6. 기간: 2026-06-01 ~ 08-31

**[화면]** Toast "등록 완료, 알림 발송"

**[나레이션]**
"항공방제 보조금, 총 예산 5억 원, 70퍼센트를 지원하고 건당 한도는 500만 원입니다. 등록하면 대상 농업인에게 자동으로 알림이 발송됩니다."

> 촬영 포인트: 지원 비율 70%와 예산 5억을 클로즈업.

## Scene 10: 대행단 생성 (40초)

**[화면]** 작업자 이철수 앱 — "대행단 만들기" 탭

**[나레이션]**
"청년농 이철수가 대행단을 만듭니다."

**[액션]** 순서대로 입력:
1. 팀명: 부량 콤바인팀
2. 대표: 이철수
3. 전문분야: 벼베기, 로터리
4. 서비스 지역: 김제시 전체 (반경 30km)

**[나레이션]**
"부량 콤바인팀, 벼베기와 로터리 전문, 김제시 전체를 서비스합니다. 팀 로고와 작업 사진도 등록해서 의뢰자에게 신뢰를 줍니다."

> 촬영 포인트: 팀명, 전문분야, 서비스 지역 입력을 순서대로 보여줄 것.
