DB 스키마 현황 (Alembic 마이그레이션)
파일 생성 테이블 주요 컬럼 / 제약조건
0001_create_user_table.py users UUID PK, phone UNIQUE, current_role, refresh_token, is_admin, avg_rating
0002_create_job_tables.py jobs job_applications jobs: requester_id FK, category, location_lat/lng, area_pyeong, ARRAY(equipment_tags), status, is_urgent
job_applications: UNIQUE(job_id, applicant_id)
0003_create_drying_tables.py drying_facilities drying_reservations reservations: input_kg, output_kg, yield_pct, moisture_pct, color_grade, quality_grade, status(PENDING/APPROVED/COMPLETED)
0003b_create_chat_tables.py chat_rooms chat_messages chat_rooms: UNIQUE(job_id)
chat_messages: content String(1000), is_read
0004_create_notifications_table.py notifications fcm_tokens fcm_tokens: UNIQUE(user_id, device_type)
0005_create_reviews_table.py reviews CheckConstraint(rating BETWEEN 1 AND 5), UNIQUE(job_id, reviewer_id)
+ users 테이블에 avg_rating, is_admin 컬럼 추가
0006_create_payments_table.py payments UNIQUE(job_id), amount, status(PENDING/CONFIRMED)
주의: ARRAY 타입(equipment_tags, available_crops)은 PostgreSQL 전용. 테스트는 sqlite+aiosqlite:///:memory: 사용 (ARRAY 컬럼 nullable 처리).
