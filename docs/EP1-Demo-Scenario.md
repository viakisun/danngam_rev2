# EP1 데모 시나리오 — 초기데이터 + 작업자 온보딩

> 백오피스 데이터 구축 → 작업자 가입 → 장비 등록 → 장비 조회

## Micro Steps

### Step 1: 백오피스 로그인
- [Click] 백오피스 로그인 → [State] 관리자 대시보드 → [Auto] "초기 데이터 구축" 배너

### Step 2: 농작업-농기계 매칭 DB
- [Click] "농작업-농기계 매칭 DB 관리" → [Panel] 시기별 농작업 테이블
- [Input] 3월/벼/로터리작업/트랙터(30마력 이상)+로터리/평당 3,000~5,000원 → [Click] 저장

### Step 3: 농기계 카테고리
- [Click] "농기계 카테고리 관리" → [Input] 트랙터 > 대동 RX7630 > 76마력/4WD/로터리 호환
- [Upload] 제품 이미지 2장 → [Click] 저장

### Step 4: 일괄 업로드
- [Click] "데이터 일괄 업로드" → [Upload] 초기데이터_농기계_v1.xlsx (50건)
- [Auto] 유효성 검사 → "48건 성공, 2건 오류" → [Modal] 오류 상세

### Step 5: 앱 로그인
- [Click] 앱 실행 → "카카오로 시작하기" → [Auto] 인증 → 위치 권한 → 홈 화면 (김제시 부량면)

### Step 6: 홈 화면
- [Auto] "주변 5km 장비 3건" 배너 + "3월 추천: 로터리 작업" 카드

### Step 7: 장비 리스트
- [Click] "주변 장비 보기" → 장비 카드 3건 (사진+모델명+보유자+거리+평점)

### Step 8: 장비 상세
- [Click] 첫 번째 카드 → 대동 RX7630 76마력, 부착장비(로터리/쟁기/배토기), 이철수, 4.8점

### Step 9: 장비 등록
- [Click] "내 장비 등록" → 카테고리 → 모델 → [Auto] 스펙 자동입력 → 사진 3장
- 부착장비 체크 → 지역: 김제시 반경 20km → 가격: 평당 4,000원 → 등록

### Step 10: 시기별 추천
- [Click] 홈 → "이번 달 추천" → "9월 벼베기" → 알림 설정 → "알림 설정 완료"
